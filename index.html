④ 说明书 · 胜率速查 —— 怎么用、每档什么胜率，都在这

▎每天怎么用（3步，共约5分钟）
收盘后：跑 python daily_tracker.py --update 刷新看板（盘中跑也安全：实时半根K线只用于显示，不会污染历史数据，收盘后正式数据照常入库）→ 看导航①区今天急跌入池了哪些新票（登记即可，不用操作）。
第二天盘中：中午、14:30 各再跑一次 --update → 看②区「vs预警线」列盯收盘价（红底=现价跌破D0最低线，尾盘收不回来①项就不成立）。
第二天14:30后：核对四项定夺——①收盘站回D0最低价上方（上午碰破不要紧，尾盘还在线下=放弃）②收阳 ③站回MA5 ④量比≥1 → 通过则在 13:00-14:55 买入，次日10:30前卖出。

▎涨停基因窗口（20日）与新鲜度：入池门槛 = 20 个交易日内有过涨停。回测验证（n=9478 确认事件）：距涨停 1~2 天 / 3~5 / 6~10 / 11~15 / 16~20 天确认的票，后续 10 日大涨率 45.6% / 44.9% / 47.0% / 47.3% / 44.1%——基本无衰减，不存在"超过10天失效"；新鲜度（≤5天）只影响①区「优先分」的排序（先盯谁），不影响确认档位本身。另一个口径勿混淆：大涨日前置画像中"10日内涨停加成"（48.6% vs 无涨停23.5%）说的是预测任意一天的普涨，与本体系"急跌→确认"的胜率是两回事。
▎「核对日」与四项逐项打勾（②区）
每只票四个信号 ●到位 / ✗未到位 / –还没轮到，逐项标在②区表格里。「核对日」列显示当前核到第几天：D1 没凑齐的票会自动滚动到最新交易日继续核（近一年回测：27% 的票要等 D2~D5 才确认，且晚确认质量不打折——D1 43.6% / D2 47.3% / D5 48.7%）。四项全中的当天就是确认日，当天 13:00-14:55 买入、次日卖；超过 5 天还没凑齐（核到 D5 仍缺项），放弃。
▎「D0最低价」vs「今日收盘(现)」（②区两列并排）：左列 = D0预警线锚（固定不变，整个 D1~D5 窗口都比它），右列 = 核对日收盘价（盘中=实时最新价，即"若现在收盘"的收盘价，每20秒刷新，带 今 标 = 正在用当日实时数据；收盘后=正式收盘价）；右列低于左列 = 收盘价破线（红底「破线」）——①项口径就是收盘>D0最低价，这列直接实时盯①项成不成立，盘中碰线不破收盘不算失败——两列放一起就是为了不用来回翻①区找锚价。 ▎「D0性质」—— 今天这根急跌是洗盘还是出货？（全历史 n=26608 回测）
● 偏洗盘 = 放量急跌(量比≥1.2) + 涨停1~2天内：下跌有承接、分歧换手充分，次日反抽概率最高，确认率 15.5%（基线7.3%的2倍+），优先盯。
▼ 偏出货 = 缩量阴跌(量比<0.7)：没有资金接、阴跌磨人，次日确认率仅 3.0%；其中缩量+涨停1~2天的最坑，确认后次日卖出均值 -2.29%（全表最差），直接跳过、别浪费精力。
中性 = 其余组合，按四项确认正常流程走。
⚠️ 反直觉提醒：教科书说"缩量回调是洗盘"，在这套体系里恰恰相反——缩量急跌+涨停1~2天内的票，次日卖出均值 -2.29% 是全表最差（缩量=没人接盘，不是筹码稳定）；真正的好信号是放量+涨停新鲜。注意：偏洗盘≠能买，D0当天仍然禁止买入（负期望），它只决定"明天值不值得重点盯"。
▎「K位置60日」（②区）：D0收盘处在最近60日高低区间的百分位。全历史验证：胜率对位置不敏感（确认组低位71.7% ~ 顶部75.6%，高位前半场78.0%/后半场73.3%）——但风险不对称：位置>85%的高位票万一失败，10日内最大回撤中位 -14.9%（非高位仅-8.7%）。高位票可参与但减半仓，破D1最低价立刻离场。 ▎「确认后逐日」（③区）：D1~D5每天涨幅色块 ≥6%涨跌未走，一眼看出确认后哪天涨的。
